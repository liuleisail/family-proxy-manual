# v0.11.17 — 升级后的管理配置读取与存储恢复

修复 NAS 存储重挂载后，代理规则页面无法读取 Mihomo 配置、DNS 过滤页面一直加载、更新任务无法创建备份的问题。

- 新增宿主机与管理服务挂载视图的实际文件读取对照。只有宿主机正常且服务明确出现 ENOTCONN/ESTALE 时，才备份并重启对应管理服务。
- 每分钟检查，维护事务执行中推迟恢复，每服务恢复尝试至少间隔五分钟。不会启动未运行服务、重启 Mihomo/MosDNS 核心或改动 RouterOS。
- Mihomo 升级前后验证规则/过滤管理能力；管理读取失败与核心失败分开报告，避免错误回滚正常的新核心。
- MosDNS 后台维护结束后触发主机检查；配置写操作和后台任务使用维护锁保护。
- 规则/过滤页面显示明确的读取失败状态和请求超时，完整部署同步安装新版 DNS 页面并验证实际规则 API。

验证包括失效挂载恢复、故障隔离、事务锁与恢复限频的回归，以及核心升级前阻断、升级后管理失败不回滚、页面 API 错误显示。保留备份、原有规则、过滤模式和查询上游。

本版本处理已确认的故障类型；底层 NAS 存储不可用时只报告问题，不能保证所有硬件、网络或外部下载源永不发生故障。生产环境不主动制造 FUSE 断连。

发布验证：106 项回归测试、Vue 类型检查、Vite 构建及发布校验通过。NAS 已部署 0.11.17（build `bd5c92d8c912`），规则页面/状态接口、主机存储检查、DNS 探针和 Netwatch 验证通过；两个核心容器与关键配置哈希保持不变。
