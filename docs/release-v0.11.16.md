# v0.11.16 - Audit Safety Fixes

## 修复

- 单设备规则按完整标签匹配，避免短 IP 前缀误删其它设备。
- 设备加入/撤出使用线程与文件锁；原子保存名单，先准备接收端，再接通 RouterOS 流量，回滚异常明确报告。TPROXY 同步另行串行化。
- 复合健康覆盖 TPROXY TCP/UDP 监听、策略路由、nft 规则与名单一致性；明确失活的候选不再算健康。
- 新旧设备页面区分转发就绪、近期观察到旁路流量和降级；禁用规则或普通直连连接不再代表旁路生效。
- MosDNS 备份、下载、预检失败保持现有核心容器；进入实际切换后才执行旧镜像回滚。
- Docker 恢复改为显式白名单，排除优先并支持维护暂停，不默认接管其它 NAS 服务。
- APNs 旧地址表清理使用明确的 RouterOS address-list 路径。

## 部署与兼容

- 保留此前工作区中的 HomeKit 路由和 Mihomo 升级数据挂载保护。
- 修复源码同步目录保持、build 指纹一致性及 18088 入口等待；部署包括 MosDNS 维护 API 和 Docker helper 的备份安装。
- 不升级 Mihomo/MosDNS 核心，不修改 RouterOS 策略或设备名单；已有旧 APNs 列表为空时无需重新导入模板。
- Docker 恢复默认白名单为空；已有部署应明确选择需要 opt-in 的本项目容器，维护期间可使用暂停文件。
